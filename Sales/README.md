# Sales

Pipeline automation: get opportunities into the CRM fast, and keep them moving. Patterns here are **event → deal** and **scheduled pipeline hygiene**.

| Blueprint | What it does |
|---|---|
| [Meeting Booked → Deal](meeting-booked-to-deal/) | Calendar booking → contact + open deal + rep notified |
| [Stale Deal Reminder](stale-deal-reminder/) | Daily nudge on deals idle 7+ days |

**Planned:** quote generator, won-deal handoff, lost-deal reasons, round-robin assignment, renewal reminders. See [roadmap](../docs/roadmap.md).
