# Screenshots & demo GIFs

This folder holds the visual assets referenced across the docs and blueprint READMEs. Add your own as you import and run each scenario — real screenshots from *your* Make account make the portfolio credible.

## Suggested shots to capture

| File | What to capture |
|---|---|
| `import-blueprint.png` | The Import Blueprint dialog with a `blueprint.json` selected |
| `lead-capture-canvas.png` | The Lead Capture scenario laid out on the canvas |
| `support-triage-run.png` | A successful Support Triage run with the JSON output bundle expanded |
| `ops-digest-slack.png` | The Daily Ops Digest message in Slack |
| `error-handler.png` | A module with its `onerror` → Break handler visible |

## Demo GIFs

Record a 5–10s GIF of:
- Importing a blueprint and reconnecting an app.
- A webhook firing → scenario running → Slack notification appearing.

Tools: [ScreenToGif](https://www.screentogif.com/) (Windows), [Kap](https://getkap.co/) (Mac), or Make's own run-history view.

## Tips

- Crop to the relevant modules; full-canvas shots are hard to read in a README.
- Blur any real connection names, account emails, or data before committing.
- Keep files under ~1 MB so the repo stays light (optimize PNGs / cap GIF length).
